# Classes da Jornada

> Rascunho, não implementado ([README.md](README.md)).

As classes são as origens do Roleta ([origens.md](../base/origens.md)), com um corte: cada classe é uma árvore de talentos inteira ([progressao.md](progressao.md)).

## Desbloqueios

| Classe | Como libera |
|---|---|
| Comum | Inicial |
| Prodígio | Subclasse do Comum: o Comum que vem sem elementos |
| Uchiha | Vencer no Médio ou acima com um shinobi de fogo |
| Hyuuga | Vencer no Médio ou acima com o prodígio |

## Easter eggs

- Algumas combinações liberam personalização e ramos especiais da árvore. Ex.: Uchiha + raio + Chidori → personalização do Uchiha e um ramo ligado ao Sasuke.

## Versão suporte

- Os suportes genéricos precisam de uma **versão suporte** de cada classe: comportamento automático e progressão simples, sem árvore.
