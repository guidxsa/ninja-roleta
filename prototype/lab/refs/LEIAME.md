# Imagens base dos retratos (auditoria)

Uma imagem de referência por retrato, para comparar com o desenho em SVG de `prototype/portraits/` e ajustar um a um.

- **Nome do arquivo**: a chave da tabela, com `.png`, `.jpg` ou `.webp` (ex.: `naruto.png`, `hakuCivil.jpg`).
- **Enquadramento**: quadrado, rosto e ombros de frente, 512px ou mais. A galeria corta em quadrado, com o foco no alto.
- **Onde aparece**: só no UI Lab. `npm run lab` copia a pasta para `dist-lab/refs/` e o cenário `meta.portraits` mostra a imagem ao lado do desenho (`&refs=com` filtra os que já têm imagem, `&refs=sem` os que faltam). O jogo (`dist/`) nunca lê esta pasta.
- **Direitos**: são referências de trabalho, de terceiros. Ficam fora do git (`.gitignore`) e da licença do código; só este arquivo é versionado.

Situação: **pendente** (sem imagem), **enviado** (imagem na pasta, desenho por ajustar), **aprovado** (o usuário aprovou o desenho).
